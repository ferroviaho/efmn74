Teste das entradas dos sensores S10 a S14

Programa de referência para testar individualmente os cinco sensores Hall A3144E da GA3. Esta página apresenta o procedimento previsto e o código de bancada. Os testes e os resultados de S10 a S14 ainda não foram registrados como concluídos.

O GPIO32 é usado somente para o ensaio sequencial, conectando um sensor de cada vez. A distribuição definitiva de GPIOs dos cinco sensores deve ser conferida antes da instalação. O GPIO33 já constava como ocupado e não deve ser presumido disponível.

Preparação

  1. Desligar a alimentação antes de montar ou mudar as conexões. Identificar corretamente os terminais VCC, GND e OUT do A3144E pelo modelo físico e pela folha de dados.
  2. Ligar o VCC do sensor a 3V3 da ESP32, o GND à barra GND comum e o OUT ao GPIO32, utilizando o fio verde do sinal.
  3. Conectar um resistor de 4,7 kΩ entre OUT e 3V3, como pull-up externo. Nunca ligar a saída do sensor a 5 V diretamente na entrada da ESP32.
  4. Selecionar a placa e a porta na Arduino IDE, carregar o código e abrir o Monitor Serial em 115200 baud.
  5. Aproximar e afastar um ímã do sensor, observando a mudança de estado. Repetir o procedimento para S10, S11, S12, S13 e S14.
Atenção: verificar a orientação dos terminais antes de energizar. O sensor A3144E tem saída de coletor aberto e requer pull-up. O programa demonstra detecção de campo magnético e não substitui a lógica definitiva de segurança ou a identificação de passagem de trens.

Código-fonte completo

// EFMN 74 - GA3 - Teste individual dos sensores Hall S10 a S14
// Conectar um sensor por vez ao GPIO32, com resistor externo de 4k7.
// A3144E: saida em LOW quando o campo magnetico atua.

const int PINO_HALL = 32;
const unsigned long INTERVALO = 40;
int ultimoEstado = HIGH;
unsigned long ultimaLeitura = 0;

void setup() {
  Serial.begin(115200);
  pinMode(PINO_HALL, INPUT); // Pull-up EXTERNO 4k7 a 3V3
  delay(400);
  ultimoEstado = digitalRead(PINO_HALL);
  Serial.println("GA3 - Teste dos sensores Hall S10 a S14");
  Serial.println("Conecte um sensor por vez ao GPIO32.");
  Serial.println("LOW = campo detectado; HIGH = sem deteccao.");
  Serial.println("Aproxime e afaste o ima do sensor.");
}

void loop() {
  if (millis() - ultimaLeitura >= INTERVALO) {
    ultimaLeitura = millis();
    int estado = digitalRead(PINO_HALL);
    if (estado != ultimoEstado) {
      ultimoEstado = estado;
      if (estado == LOW) {
        Serial.println("LOW - campo magnetico detectado");
      } else {
        Serial.println("HIGH - campo magnetico ausente");
      }
    }
  }
}
