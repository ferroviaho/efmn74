GA3 – Testes dos 4 módulos Mosfets

Código-fonte de referência dos testes realizados nos quatro módulos Mosfet da GA3. O relatório de medições e procedimentos pode ser consultado em Biblioteca → Testes realizados, na página Testes dos 4 Mosfets da GA3.

Finalidade

Comandar um módulo Mosfet de cada vez pela ESP32, alternando a saída de controle entre LOW e HIGH, e conferir a resposta elétrica com multímetro e com a carga conectada.

O GND dos módulos deve compartilhar a barra GND comum da GA3 e o GND da ESP32. O Mosfet 1 tem Vin+ conectado a X0+ e GND à barra GND. Não presumir os GPIOs definitivos dos Mosfets 3 e 4 a partir dos testes provisórios.

Procedimento de teste

  1. Desligar a alimentação e conferir a identificação dos terminais de entrada, saída e controle de cada módulo.
  2. Conectar o GND da ESP32 ao GND comum da GA3. Conferir também a ligação de terra do módulo.
  3. Conectar o fio PWM de controle ao GPIO escolhido para o ensaio.
  4. Selecionar a placa e a porta corretas na Arduino IDE. Enviar o programa abaixo.
  5. Medir a resposta elétrica nos pontos adequados do módulo. Confirmar a alternância entre aproximadamente 0 V e 4,9 V observada nos ensaios de bancada.
  6. Repetir o teste separadamente para os quatro módulos. Antes de trocar ligações, desligar a alimentação.
Atenção: as medições devem ser realizadas com referência de GND correta. Não confundir a entrada de controle com a saída destinada à carga. A forma de ligação da carga depende do modelo físico do módulo Mosfet.

Código-fonte completo

Alterar somente a constante PINO_MOSFET para o GPIO efetivamente utilizado. Exemplo: Mosfet 1 = 26. Mosfet 2 = 14.

// EFMN 74 - GA3 - Teste individual de modulo Mosfet
// Testar um modulo de cada vez.
// Mosfet 1: GPIO26. Mosfet 2: GPIO14 no ensaio.

const int PINO_MOSFET = 14; // Ajustar ao modulo em teste
const unsigned long INTERVALO = 2000;
unsigned long ultimaTroca = 0;
bool ligado = false;

void setup() {
  Serial.begin(115200);
  pinMode(PINO_MOSFET, OUTPUT);
  digitalWrite(PINO_MOSFET, LOW);
  Serial.println("GA3 - Teste individual de Mosfet");
  Serial.println("Alternancia LOW / HIGH a cada 2 segundos");
}

void loop() {
  if (millis() - ultimaTroca >= INTERVALO) {
    ultimaTroca = millis();
    ligado = !ligado;
    digitalWrite(PINO_MOSFET, ligado ? HIGH : LOW);
    Serial.println(ligado ? "HIGH - comando ativo" :
                            "LOW - comando inativo");
  }
}
