TTD-01 — Teste e ajuste de desvios

O Testador Temporário de Desvios (TTD-01) é usado em duas etapas: primeiro, testar todos os motores (servos SG90), um por vez, antes de qualquer instalação; depois, assim que cada desvio e seu motor forem instalados na maquete, fazer um novo ajuste do movimento das agulhas naquele conjunto.

A sequência é: testar todos os motores → instalar um desvio com seu motor → ajustar esse desvio → repetir a instalação e o ajuste nos demais. O teste do motor na bancada verifica seu funcionamento; as posições finais DI e AC são definidas individualmente após a instalação.

Nos dois casos, o notebook envia os comandos para uma ESP32 usada como testador, que movimenta um servo por vez. Os desvios não possuem sensores Hall: a conferência do assentamento das agulhas é visual.

1. Material necessário

ESP32, notebook com Arduino IDE, cabo USB de dados, motores SG90, jumpers e protoboard. Conectar somente um motor por vez. Para o ajuste após a instalação: desvio com seu motor, braço e haste montados, além de extensões para os fios, se necessário.

2. Ligações

Montar ou alterar as ligações com o USB desconectado e a alimentação da maquete desligada. Testar um servo por vez. Se ele já estiver instalado, desligar seus três fios do circuito definitivo antes de ligá-los ao TTD-01.

Fio do servoLigação
Vermelho5 V da ESP32 alimentado pelo USB
Marrom ou pretoGND da ESP32
Laranja ou amareloGPIO 18 da ESP32

Confirmar que o ponto de 5 V da placa recebe alimentação pelo USB; não usar 3V3 para o servo. No teste individual, o notebook pode alimentar a bancada, dispensando fonte externa se a alimentação permanecer estável. Se a ESP32 reiniciar ao mover o servo, interromper o teste e conferir a alimentação.

3. Preparar e gravar o programa

  1. Na Arduino IDE, instalar o pacote esp32 da Espressif pelo Gerenciador de Placas e a biblioteca ESP32Servo pelo Gerenciador de Bibliotecas. Se necessário, acrescentar nas Preferências a URL: https://espressif.github.io/arduino-esp32/package_esp32_index.json.
  2. Conectar a ESP32 ao notebook, selecionar a placa correspondente e a porta USB. Para a ESP32 clássica genérica deste exemplo, selecionar ESP32 Dev Module.
  3. Abrir um novo sketch, substituir o conteúdo pelo código abaixo e salvar como TTD01_Servo.
  4. Clicar em Verificar. Se houver erro, conferir a primeira mensagem e corrigir antes de prosseguir.
  5. Com o servo desconectado, clicar em Carregar para gravar na ESP32. Se ficar em Connecting, manter BOOT pressionado até iniciar a transferência.
  6. Desconectar o USB, ligar o servo conforme a tabela e reconectar. Abrir o Monitor Serial em 115200 baud, com final de linha Nova linha.
Código do teste — clicar para abrir

Enviar C para 90°, D para 80° ou A para 100°. Também é possível enviar um número de 60 a 120 para ajustar aos poucos. Esses valores são apenas um ponto de partida.

#include <ESP32Servo.h>

constexpr int SERVO_PIN = 18;
constexpr int DIRECT_POSITION = 80;
constexpr int ACCESS_POSITION = 100;
constexpr int CENTER_POSITION = 90;
constexpr int MIN_POSITION = 60;
constexpr int MAX_POSITION = 120;

Servo testServo;
String command;

void moveServo(int position) {
  if (position < MIN_POSITION || position > MAX_POSITION) {
    Serial.println("Position outside test range: 60 to 120.");
    return;
  }
  if (!testServo.attached()) {
    testServo.setPeriodHertz(50);
    testServo.attach(SERVO_PIN, 1000, 2000);
  }
  testServo.write(position);
  Serial.print("Commanded position: ");
  Serial.println(position);
}

void processCommand(String text) {
  text.trim();
  text.toUpperCase();
  if (text.length() == 0) return;
  if (text == "D") { moveServo(DIRECT_POSITION); return; }
  if (text == "A") { moveServo(ACCESS_POSITION); return; }
  if (text == "C") { moveServo(CENTER_POSITION); return; }
  if (text == "S") {
    testServo.detach();
    Serial.println("Control pulses stopped. USB power is still on.");
    return;
  }
  bool numeric = true;
  for (unsigned int i = 0; i < text.length(); ++i) {
    if (text[i] < '0' || text[i] > '9') numeric = false;
  }
  if (numeric) { moveServo(text.toInt()); return; }
  Serial.println("Use D, A, C, S, or a number from 60 to 120.");
}

void setup() {
  Serial.begin(115200);
  command.reserve(24);
  Serial.println("TTD-01 servo test ready. Servo output: GPIO 18.");
  Serial.println("Use D, A, C, S, or a number from 60 to 120.");
  // Servo control starts only after a movement command.
}

void loop() {
  while (Serial.available()) {
    char c = Serial.read();
    if (c == '\n') {
      processCommand(command);
      command = "";
    } else if (c != '\r') {
      if (command.length() < 24) command += c;
      else {
        command = "";
        Serial.println("Command too long. Send one short command per line.");
      }
    }
  }
}

4. Testar todos os motores antes da instalação

Antes de iniciar as instalações, testar todos os motores individualmente na bancada. Nesta etapa, o motor fica livre, sem ligação às agulhas de um desvio.

  1. Identificar o primeiro motor. Com o USB desconectado, ligar seus três fios ao TTD-01 conforme a tabela do item 2.
  2. Conectar o USB e abrir o Monitor Serial. Enviar C para 90°, depois D e A, um comando por vez. Conferir se o eixo se movimenta nos dois sentidos.
  3. Alternar D → A → D várias vezes. O movimento deve ser regular e repetível, sem travamento, vibração contínua, aquecimento anormal ou reinicialização da ESP32. Nesta etapa, D e A são apenas posições de teste do motor livre.
  4. Enviar C para deixar o motor em 90° e desconectar o USB. Registrar a identificação do motor, os valores angulares usados no teste, os ciclos realizados e o resultado. Com o código inicial, os valores são C = 90°, D = 80° e A = 100°; se forem alterados, anotar os valores efetivamente utilizados. Separar os aprovados dos que precisam de nova conferência.
  5. Retirar o motor testado, conectar o próximo com o USB desligado e repetir o procedimento até testar todos os motores.

Concluído o teste de todos os motores, iniciar as instalações usando os aprovados. Guardar as anotações de cada motor para acompanhar a instalação. A posição de 90° facilita a montagem inicial do braço; os valores usados na bancada são referências e as posições finais DI e AC devem ser ajustadas e anotadas após instalar cada desvio.

5. Ajustar cada desvio logo após a instalação

Assim que um desvio, seu motor, braço e haste forem instalados na maquete, usar o TTD-01 para ajustar o movimento daquele conjunto. Fazer isso em cada instalação, mesmo que o motor tenha sido aprovado na bancada. A posição e a fixação da haste determinam o curso necessário para as agulhas.

O desvio permanece nos trilhos e o TTD-01 comanda temporariamente seu motor. Após concluir o ajuste e a conferência desse desvio, instalar e ajustar o próximo.

  1. Retirar as locomotivas da região do teste, desligar a alimentação da maquete e desconectar o USB do testador. Identificar o desvio e anotar os valores de DI e AC já usados, se estiverem disponíveis.
  2. Se o servo já estiver ligado ao circuito definitivo, desconectar seus três fios — positivo, GND e sinal. Se ainda não estiver ligado, conectá-lo diretamente ao TTD-01. Em ambos os casos, ligar somente esse servo ao testador, conforme o item 2. Usar extensões, se necessário, para alcançar o servo sob a maquete. Não unir o positivo do testador ao barramento da maquete. Durante o teste, não conectar o fio de sinal do servo à ESP32 da gaveta GA3; o sinal deve ficar ligado somente à ESP32 do TTD-01.
  3. Se os valores anteriores forem conhecidos e o mecanismo estiver livre, colocá-los em DIRECT_POSITION e ACCESS_POSITION e gravar o testador com o servo desconectado. Reconectar o servo com o USB desligado. Ao energizar, começar enviando o valor numérico correspondente à posição em que o desvio estava; não começar com C ou com os valores padrão de 80° e 100° sem verificar se são adequados à montagem.
  4. Na primeira instalação, as posições finais ainda precisam ser encontradas. Se não houver valores de ajuste conhecidos para esse conjunto instalado, desacoplar a haste do braço do servo antes de comandar qualquer movimento. Com o servo livre, enviar C. Desligar o USB, recolocar o braço e a haste com as agulhas aproximadamente no meio do percurso e sem esforço, e então religar. Não girar o eixo do servo à força.
  5. Partindo do valor conhecido ou do centro preparado na etapa anterior, variar um grau por vez até obter o assentamento correto em DI. Anotar o valor. Depois, percorrer gradualmente o outro sentido até obter AC e anotar o segundo valor. Observar as agulhas por cima e a haste e o braço por baixo da maquete.
  6. Se a haste raspar, entortar excessivamente ou travar, desligar o USB e corrigir o alinhamento ou a fixação antes de continuar. Aumentar o ângulo não corrige uma obstrução mecânica.
  7. Atualizar os dois valores no código do TTD-01 e gravar novamente com o servo desconectado. Religar conforme o item 3 e repetir DI → AC → DI, verificando o assentamento nas duas posições.
  8. Ao terminar, desconectar o USB e, com a maquete ainda desligada, retirar as ligações do testador e reconectar os três fios do servo ao circuito definitivo. Atualizar no programa da ESP32 da gaveta GA3 os valores de DI e AC desse desvio. Usar a mesma configuração de pulsos do servo para que os valores correspondam ao ajuste feito no TTD-01.
  9. Religar a maquete e comandar esse desvio pelo controle definitivo. Conferir novamente DI e AC antes de liberar a circulação.

Registrar os valores encontrados para esse desvio antes de passar ao próximo: não copiar automaticamente o ajuste de outro conjunto. Os valores 67° e 97° utilizados na EFMN 74 são referências; cada desvio precisa de ajuste próprio.

O ajuste termina somente depois dessa conferência pelo controle definitivo. O comando S interrompe os pulsos de controle, mas não corta a alimentação do servo; para alterar ligações ou o mecanismo, desconectar o USB.

6. Resultado e registro

Antes da instalação, aprovar cada motor quando apresentar movimento regular e repetível, sem travamento, vibração contínua, aquecimento anormal ou reinicialização da ESP32. Registrar sua identificação, os valores angulares usados no teste, os ciclos realizados e o resultado.

Após cada instalação, aprovar o desvio quando suas agulhas assentarem corretamente em DI e AC, sem esforço contínuo, e o movimento se repetir tanto no TTD-01 quanto no controle definitivo. Registrar a identificação do desvio, os valores finais de DI e AC, os ciclos realizados e o resultado. Confirmar que os valores foram atualizados no programa da ESP32 da gaveta GA3.
