GA3 – Testes dos servos SG90

Biblioteca → Programas da ESP32. Código-fonte de referência para reproduzir os testes dos cinco servos SG90 da GA3. O programa abaixo foi reorganizado a partir dos procedimentos registrados, não sendo uma cópia verificada do arquivo original usado nos testes.

Identificação dos servos e GPIOs

DesvioGPIO da ESP32Cor do sinal
D513Laranja
D618Azul
D819Amarelo
D921Branco
D1022Marrom

Preparação

  1. Instalar a biblioteca ESP32Servo no Gerenciador de Bibliotecas da Arduino IDE.
  2. Conferir cada ligação do sinal no GPIO indicado. O fio vermelho do servo vai ao +5 V protegido pelo relé e o GND do servo vai à barra GND comum.
  3. Alimentar os servos por fonte externa de 5 V adequada e unir o GND dessa fonte ao GND da ESP32. Não alimentar os cinco servos diretamente pelo pino 5 V ou pela USB da placa.
  4. Manter as hastes livres de cargas mecânicas. Selecionar a placa e a porta na IDE, carregar o código e abrir o Monitor Serial em 115200 baud.
Atenção: os ângulos de 60°, 90° e 120° são valores conservadores de demonstração. Ajustar os limites de cada desvio após observar a mecânica, sem forçar a haste contra batentes. O código não substitui as proteções operacionais definitivas da GA3.

Comandos de teste

TeclaOperação
TTesta D5, D6, D8, D9 e D10, um por vez.
AExecuta dez movimentos aleatórios, retornando ao centro após cada movimento.
PComanda os pares D5/D6 e D8/D9. D10 é testado pelo comando T.
RRetorna os cinco servos à posição central.

Código-fonte completo

#include <ESP32Servo.h>

// EFMN 74 - GA3 - Testes dos servos SG90
// Comandos no Monitor Serial: T, A, P e R
// T = cada servo, um de cada vez
// A = dez movimentos aleatorios
// P = movimentos em pares
// R = retorna os cinco servos a 90 graus

const int QUANTIDADE = 5;
const char* nomes[QUANTIDADE] = {"D5", "D6", "D8", "D9", "D10"};
const int pinos[QUANTIDADE] = {13, 18, 19, 21, 22};
Servo servos[QUANTIDADE];

const int CENTRO = 90;
const int POSICAO_A = 60;
const int POSICAO_B = 120;
const unsigned long PAUSA = 600;

void mover(int i, int angulo) {
  Serial.print(nomes[i]);
  Serial.print(" -> ");
  Serial.println(angulo);
  servos[i].write(angulo);
  delay(PAUSA);
}

void centralizar() {
  for (int i = 0; i < QUANTIDADE; i++) {
    mover(i, CENTRO);
  }
}

void testeIndividual() {
  Serial.println("TESTE INDIVIDUAL");
  for (int i = 0; i < QUANTIDADE; i++) {
    mover(i, POSICAO_A);
    mover(i, POSICAO_B);
    mover(i, CENTRO);
  }
}

void testeAleatorio() {
  Serial.println("DEZ MOVIMENTOS ALEATORIOS");
  for (int n = 0; n < 10; n++) {
    int i = random(QUANTIDADE);
    int angulo = random(2) == 0 ? POSICAO_A : POSICAO_B;
    mover(i, angulo);
    mover(i, CENTRO);
  }
}

void testePares() {
  Serial.println("TESTE EM PARES");
  // Dois servos sao comandados sem pausa entre os comandos.
  // Evitar alimentar todos os servos pela USB da ESP32.
  for (int i = 0; i + 1 < QUANTIDADE; i += 2) {
    servos[i].write(POSICAO_A);
    servos[i + 1].write(POSICAO_B);
    Serial.print(nomes[i]);
    Serial.print(" + ");
    Serial.println(nomes[i + 1]);
    delay(PAUSA);
    servos[i].write(CENTRO);
    servos[i + 1].write(CENTRO);
    delay(PAUSA);
  }
  // D10 permanece fora dos pares e e testado individualmente.
}

void setup() {
  Serial.begin(115200);
  delay(500);
  // ESP32Servo: instalar a biblioteca pelo Gerenciador da IDE.
  for (int i = 0; i < QUANTIDADE; i++) {
    servos[i].setPeriodHertz(50);
    servos[i].attach(pinos[i], 500, 2400);
  }
  randomSeed(micros());
  centralizar();
  Serial.println("Digite T, A, P ou R no Monitor Serial.");
}

void loop() {
  if (Serial.available()) {
    char comando = toupper(Serial.read());
    switch (comando) {
      case 'T': testeIndividual(); break;
      case 'A': testeAleatorio(); break;
      case 'P': testePares(); break;
      case 'R': centralizar(); break;
      case '\n': case '\r': break;
      default: Serial.println("Comando invalido. Use T, A, P ou R.");
    }
  }
}

Registro histórico e observações

Em 27 de outubro de 2026, os cinco servos da GA3 responderam aos testes individuais, à rotina aleatória e ao teste de acionamento em pares. Uma falha de conexão no D5 foi identificada durante os testes, com aviso de três bipes. Este programa de demonstração não implementa o buzzer nem a detecção elétrica dessa falha.

Os valores dos GPIOs apresentados refletem o mapeamento registrado da GA3. Antes de integrar esta rotina ao software definitivo, conferir eventuais alterações de pinagem e as posições mecânicas reais dos desvios.
