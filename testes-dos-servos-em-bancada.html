Teste dos servos em bancada

Os testes de bancada dos 19 servos SG90 da EFMN 74 foram concluídos. Este documento reúne o registro dos resultados e o roteiro de preparação, conexão e operação, preservado para consulta e para novos servos.

Resultados dos testes concluídos

Os 19 servos foram testados individualmente com um programa carregado pela Arduino IDE. Todos responderam aos comandos. Os cinco servos da GA3, D5, D6, D8, D9 e D10, responderam aos testes individuais e em pares, com as hastes livres.

Os servos já aprovados não precisam repetir os testes por causa desta consolidação. O roteiro abaixo fica como referência. A aprovação em bancada não substitui o ajuste após a instalação no desvio.

Registro em vídeo

1. Preparar a bancada

  1. Separar o notebook com Arduino IDE, cabo USB, ESP32, protoboard, jumpers, fonte regulada de 5 V com capacidade para a corrente de partida do servo e os servos a testar.
  2. Sugere-se instalar a ESP32 na protoboard, deixando os pinos acessíveis para as conexões. Deixar espaço para o braço do servo se movimentar livremente.
  3. Conferir o encaixe da ESP32. As duas fileiras de pinos devem ficar em grupos de contatos separados, sem curto entre elas.
  4. Identificar cada servo antes do teste. Conectar somente um por vez e manter o mecanismo livre de obstáculos.
  5. Fazer ou alterar as ligações com a fonte desligada e o cabo USB desconectado.

2. Fazer as ligações

As cores abaixo correspondem ao cabo original usual do SG90. Conferir a identificação do servo antes de conectar.

Fio ou conexãoDestino
Vermelho do servoPositivo da fonte externa regulada de 5 V.
Marrom ou preto do servoNegativo da fonte externa, ligado também ao GND da ESP32.
Laranja ou amarelo do servoGPIO18 da ESP32.
Cabo USB de dadosNotebook e conector USB da ESP32.

Nesta montagem, alimentar a ESP32 pelo USB e o servo pela fonte externa de 5 V, com GND comum. Não conectar o positivo da fonte externa ao Vin nem ao 3V3 da ESP32. Não alimentar o servo pelo 3V3. Usar fios pretos para GND e vermelhos para +5 V. Conferir a polaridade antes de ligar. Se houver reinicialização ou instabilidade, interromper o teste e conferir a alimentação.

3. Preparar a Arduino IDE

  1. Abrir a Arduino IDE no notebook. Se necessário, obter o instalador compatível em arduino.cc/en/software.
  2. No Gerenciador de Placas, instalar o pacote Esp32 da Espressif Systems, se ainda não estiver instalado. Se necessário, acrescentar em Arquivo → Preferências, no campo de URLs adicionais do Gerenciador de Placas: https://espressif.github.io/arduino-esp32/package_esp32_index.json.
  3. No Gerenciador de Bibliotecas, procurar e instalar ESP32Servo. Se a configuração já funciona, preservá-la. Registrar as versões da IDE, do pacote ESP32 e da biblioteca.
  4. Conectar a ESP32 ao notebook pelo cabo USB, mantendo o servo desconectado durante a gravação.
  5. Selecionar a placa correspondente. Para a ESP32 clássica genérica deste roteiro, usar ESP32 Dev Module.
  6. Selecionar a porta correspondente à ESP32. A numeração pode mudar conforme a conexão do notebook.

4. Inserir e gravar o código

  1. Guardar o arquivo original antes de usar uma ESP32 que já controla a GA3. Carregar outro sketch substitui o programa da placa. Abrir um novo sketch. Selecionar e apagar o conteúdo inicial.
  2. Copiar todo o código da seção seguinte e colar na IDE.
  3. Salvar o sketch com o nome TTD01_Servo.
  4. Clicar em Verificar. A compilação deve terminar sem erros. Se houver erro, conferir a primeira mensagem antes de prosseguir.
  5. Clicar em Carregar. Aguardar a conclusão da gravação. Se ficar em Connecting, manter BOOT pressionado até iniciar a transferência e então soltar.
  6. Com a fonte externa desligada, desconectar o USB. Conectar o servo conforme a tabela e reconectar o USB. Manter a fonte do servo desligada até iniciar os testes.
  7. Abrir o Monitor Serial. Selecionar 115200 baud e o final de linha Nova linha.

5. Código de referência para a bancada

O programa usa GPIO18, frequência de 50 Hz e faixa de pulsos de 1000 a 2000 microssegundos. O controle do servo começa somente após o envio de um comando de movimento.

#include <ESP32Servo.h>

constexpr int SERVO_PIN = 18;
constexpr int DIRECT_POSITION = 80;
constexpr int ACCESS_POSITION = 100;
constexpr int CENTER_POSITION = 90;
constexpr int MIN_POSITION = 60;
constexpr int MAX_POSITION = 120;

Servo testServo;
String command;

void moveServo(int position) {
  if (position < MIN_POSITION || position > MAX_POSITION) {
    Serial.println("Position outside test range: 60 to 120.");
    return;
  }
  if (!testServo.attached()) {
    testServo.setPeriodHertz(50);
    testServo.attach(SERVO_PIN, 1000, 2000);
  }
  testServo.write(position);
  Serial.print("Commanded position: ");
  Serial.println(position);
}

void processCommand(String text) {
  text.trim();
  text.toUpperCase();
  if (text.length() == 0) return;
  if (text == "D") { moveServo(DIRECT_POSITION); return; }
  if (text == "A") { moveServo(ACCESS_POSITION); return; }
  if (text == "C") { moveServo(CENTER_POSITION); return; }
  if (text == "S") {
    testServo.detach();
    Serial.println("Control pulses stopped. USB power is still on.");
    return;
  }
  bool numeric = true;
  for (unsigned int i = 0; i < text.length(); ++i) {
    if (text[i] < '0' || text[i] > '9') numeric = false;
  }
  if (numeric) { moveServo(text.toInt()); return; }
  Serial.println("Use D, A, C, S, or a number from 60 to 120.");
}

void setup() {
  Serial.begin(115200);
  command.reserve(24);
  Serial.println("TTD-01 servo test ready. Servo output: GPIO 18.");
  Serial.println("Use D, A, C, S, or a number from 60 to 120.");
  // Servo control starts only after a movement command.
}

void loop() {
  while (Serial.available()) {
    char c = Serial.read();
    if (c == '\n') {
      processCommand(command);
      command = "";
    } else if (c != '\r') {
      if (command.length() < 24) command += c;
      else {
        command = "";
        Serial.println("Command too long. Send one short command per line.");
      }
    }
  }
}

6. Conhecer os comandos

ComandoResultado esperado
CComandar a posição central de 90°.
DComandar a posição de teste de 80°.
AComandar a posição de teste de 100°.
Número entre 60 e 120Comandar o valor informado, dentro da faixa permitida.
SInterromper os pulsos de controle. A alimentação permanece ligada.

Digitar um comando por vez no Monitor Serial e pressionar Enviar ou Enter. Com Nova linha selecionada, o programa recebe o terminador necessário para executar o comando.

Os valores de 80°, 90° e 100° são referências para o teste do servo livre. Não representam a calibração final dos desvios. A mensagem no Monitor Serial informa o comando enviado, não mede a posição física nem confirma o movimento.

7. Executar os testes

  1. Conferir o GND comum, a polaridade e o braço livre. Ligar a fonte externa do servo. Enviar C. Observar o servo assumir a posição central comandada. No Monitor Serial, deve aparecer Commanded position: 90.
  2. Enviar D. Observar o deslocamento para um lado. O Monitor Serial deve indicar Commanded position: 80.
  3. Enviar A. Observar o deslocamento para o outro lado. O Monitor Serial deve indicar Commanded position: 100.
  4. Alternar D → A → D várias vezes. Conferir se o movimento é regular e se o braço retorna às mesmas posições.
  5. Se necessário, testar ajustes numéricos graduais dentro da faixa de 60 a 120, sempre com o braço livre.
  6. Enviar S para conferir a interrupção dos pulsos. O programa deve informar que a alimentação USB continua ligada. A fonte externa do servo também permanece ligada. Esse comando não substitui a desconexão da alimentação.
  7. Enviar C para retomar o controle e deixar o servo na posição central. Desligar a fonte externa e desconectar o USB.
  8. Registrar o resultado. Retirar o servo e conectar o próximo somente com a alimentação desligada. Repetir até testar todos.

8. O que deve ser encontrado

  • Movimento nos dois sentidos, acompanhando os comandos.
  • Retorno repetível às posições comandadas.
  • Funcionamento sem travamento, vibração contínua ou aquecimento anormal.
  • ESP32 funcionando sem reinicializações durante o movimento.
  • Mensagens legíveis no Monitor Serial, correspondentes aos comandos enviados.

Aprovar o servo somente após observar seu funcionamento. Se houver irregularidade, interromper o teste, registrar o problema e conferir a montagem antes de repetir.

10. Se houver dificuldade

  • Porta não aparece. Conferir o cabo USB de dados e o reconhecimento da placa pelo notebook.
  • Erro de compilação. Conferir a placa selecionada, o pacote esp32 e a biblioteca ESP32Servo.
  • Texto ilegível. Conferir 115200 baud no Monitor Serial.
  • Comando não executado. Selecionar Nova linha e enviar apenas um comando por vez.
  • Servo parado. Desligar a fonte, desconectar o USB e conferir positivo, GND, sinal no GPIO18 e encaixe dos jumpers.
  • Servo tremendo ou ESP32 reiniciando. Interromper o teste e conferir a estabilidade da alimentação e das conexões.
  • Travamento ou aquecimento anormal. Desligar imediatamente e verificar se existe impedimento mecânico antes de repetir.

Uso de um testador manual independente

Se for usado um testador com controle manual próprio, seguir as marcações de sinal, positivo e GND do equipamento. Conectar com a alimentação desligada, selecionar o modo manual e mover o comando lentamente nos dois sentidos. Conferir o retorno e desligar antes de retirar o servo. Os comandos do Monitor Serial e o GPIO18 pertencem ao roteiro com ESP32 acima.

11. Depois da instalação no desvio

A aprovação na bancada verifica o funcionamento do servo livre. Depois de instalar cada servo no desvio, ajustar individualmente as posições DI e AC, observando o assentamento das agulhas e evitando esforço contínuo no mecanismo.

Os ângulos usados na bancada não devem ser aplicados automaticamente ao conjunto instalado. Registrar os valores finais de cada desvio e conferir seu funcionamento pelo controle definitivo antes de liberar a circulação.
